# Pré-alfa 0.0.0.28.43

Compilação de desenvolvimento para testes internos. A numeração acompanha a estimativa de 28,43% de maturidade da demo em 23/11/2026.

- Windows 64 bits: extraia todo o ZIP e execute o .exe na raiz da pasta extraída. A inicialização sem interface carregou o mapa e os sete destinos do Hub.
- Android ARM64: instale o APK de desenvolvimento. Assinatura verificada e compilação testada no Pixel 7 virtual. A validação em aparelho físico está pendente.

Os pacotes usam Git LFS. Em um clone que recebeu apenas os ponteiros, execute git lfs pull para baixar os binários. Os hashes estão em SHA256SUMS.txt.
